# Limits of the evidence and release

- One controlled structured editing domain, not cross-domain generalization.
- The recognition--use dissociation was model-family-specific in the tested conditions.
- G3 remains PARTIAL. Alternative wording in DSP NB/NC is NOT EVALUABLE; Stage 3d/P-D is DEFERRED.
- Serving routes and runtime identity affect interpretation. Saved metadata is not a guarantee of future provider/model availability.
- Offline saved-data reproduction does not reproduce live commercial-model responses or independently certify a remote provider's model weights.
- The public package excludes raw response text, free-form rationales and opaque reasoning payloads. Scoring begins with exported parsed structured inputs; raw textual parsing is not publicly reproducible.
- The rationale keyword result is a frozen post-hoc descriptive aggregate, not a publicly repeated text analysis.
- Historical mock-validation provenance is incomplete: exact archived analysis invocation and 30 null-validation runs are unavailable. Current synthetic tests are implementation checks, not reconstructions of missing historical runs.
- Secondary variational-Bayes fitting uses a stochastic initialization whose historical global RNG state was not archived. Full statistical comparisons report observed differences; frozen numbers are never silently replaced.
